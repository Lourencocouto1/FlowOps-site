# Fotografias dos fundadores

Coloque aqui as fotos (JPG ou PNG, pelo menos 800 × 800 px, enquadramento do peito para cima).
Depois indique o nome do ficheiro no campo "photo" de src/content/founders.json, por exemplo "lourenco.jpg".
O site gera automaticamente as versões AVIF e WebP em vários tamanhos.
